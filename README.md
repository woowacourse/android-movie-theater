# android-movie-theater

## 1단계 기능 요구 사항
- 영화 선택 후 극장을 선택할 수 있다.
- 예매 완료 화면에서 극장 이름이 길 경우 말줄임표로 표시되어야 한다. (시안 참고)
- 극장별로 상영하는 영화와 상영시간은 달라질 수 있다.
- 예를 들어 시간표를 다음처럼 구성할 수 있다.
```
선릉 극장
- 스타워즈(09시, 11시, 15시)
- 해리포터(13시, 15시, 17시, 19시)

잠실 극장
- 스즈메의 문단속(09시)
- 해리포터(10시, 12시, 14시)
- 범죄도시(11시, 13시)
```

## 1단계 구현할 기능 목록
- [ ] 예매 버튼을 누르면 극장 선택 창이 뜬다.
- 극장 선택 창
- [ ] 해당 영화를 상영하는 극장이 보여야 한다.
- [ ] 각 극장은 선택된 영화의 총 상영 시간의 개수가 보여야 한다.
- [ ] 극장을 선택하면 영화 예매 화면으로 넘어간다.
- 예매 완료 화면
- [ ] 상영 극장 이름을 화면에 출력한다.
- [ ] 너무 긴 극장 이름은 줄임표를 사용하여 출력한다.
- 영화관
- [ ] 영화관은 이름이랑 상영할 수 있는 영화 목록과 러닝 타임을 가진다.
- [ ] 영화관은 총 상영 개수를 반환할 수 있다.
- 영화관들 (Theaters)
- [ ] 영화관들(Theaters)는 모든 영화관을 가진다.
- [ ] 영화관들은 해당 영화를 상영하는 영화관 리스트를 반환할 수 있다.


- [ ] 좌석 선택 화면에서 선택한 인원 수만큼 좌석을 선택할 수 있게 변경한다.
