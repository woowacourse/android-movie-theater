# android-movie-theater

영화와 볼 극장을 선택하는 프로그램

## 기능 요구 사항

- [ ] 영화 선택 후 극장을 선택할 수 있다.
    - [ ] 극장은 영화 별로 예약 가능한 시간들을 제공한다.
- [ ] 예매 완료 화면에서 극장 이름이 길 경우 말줄임표로 표시되어야 한다.
- [ ] 극장별로 상영하는 영화는 달라질 수 있다.
- [x] 극장별로 상영시간은 달라질 수 있다.
- [ ] 하단의 네비게이션 뷰 통해 영화 예매 내역 화면으로 이동할 수 있다.
- [ ] 하단의 네비게이션 뷰 통해 홈 화면으로 이동할 수 있다.
- [ ] 하단의 네비게이션 뷰 통해 설정 화면으로 이동할 수 있다.
