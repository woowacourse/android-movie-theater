# 🚀 영화 극장 선택

## 기능 요구 사항
- 영화 선택 후 극장을 선택할 수 있다.
  - 예매 완료 화면에서 극장 이름이 길 경우 말줄임표로 표시되어야 한다.
- 극장별로 상영하는 영화와 상영시간은 달라질 수 있다.
- 예를 들어 시간표를 다음처럼 구성할 수 있다.
```agsl
선릉 극장
  스타워즈(09시, 11시, 15시)
  해리포터(13시, 15시, 17시, 19시)
  
잠실 극장
  스즈메의 문단속(09시)
  해리포터(10시, 12시, 14시)
  범죄도시(11시, 13시)
```
- 영화 예매 내역, 홈, 설정 화면으로 이동(navigate)할 수 있다.
- 내비게이션의 예매 내역 항목에 예매한 영화 목록을 보여준다.
  - 예매 내역 : 예매한 영화 목록
  - 홈 : 영화 목록
  - 설정 : 빈 화면
- 예매 내역 상세
  - 예매 내역을 터치하면 예매 정보를 보여준다.
  - 리스트 항목을 누르는 효과를 줘야 한다. (시안 참고)
- 앱을 재실행해도 기존 예매 내역이 유지되어야 한다.

## 기능 목록
### 극장 선택
- [x] 영화를 선택하면 상영중인 극장 목록이 출력된다.
- [x] 각 극장 별로 선택한 영화의 상영 시간 개수가 출력된다.

### 예매 완료
- [x] 선택한 극장이 출력된다.
- [x] 극장 이름이 길 경우 말줄임표로 표시된다.

### 예매 내역
- [x] 예매한 영화 목록이 출력된다.
- [x] 예매 내역을 터치하면 예매 정보를 보여준다.
- [x] 리스트 항목을 누르는 효과를 보여준다.
- [ ] 앱을 재실행해도 기존 예매 내역이 유지된다.
