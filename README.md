# 기능 요구 사항

### 상영 정보
- [x] 상영 정보는 '영화'와 '상영 시간'과 '좌석들'을 가진다.
- [x] 상영 정보는 지금 상영중인 영화인지 알 수 있다.

### 극장
- [x] 극장은 '이름', '상영 정보'들을 가진다.
- [x] 극장마다 '영화'와 '상영 시간'은 달라질 수 있다.
- [x] 극장 일급컬렉션은 영화와 시간, 날짜를 기준으로 상영 가능한 극장들을 가져온다.

---

### 예매 내역 저장소
- [x] 영화 예매 내역을 데이터 베이스에 저장한다.
- [x] 전체 영화 예매 내역을 데이터 베이스에서 불러온다.
- [x] 영화 예매 내역 하나를 불러온다.

### 예매 내역 화면
- [x] 영화 예매 내역 아이템은 년, 월, 일, 시간, 극장명, 영화제목을 보여준다.
- [x] 영화 예매 내역 하나를 클릭하면 예매 티켓 정보를 보여준다.
- [x] 예매 정보를 누르는 효과를 보여준다.
- [x] 앱이 재실행 될 경우에도 기존 예매 내역이 유지된다.
