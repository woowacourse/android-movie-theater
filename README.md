# 🎬 android-movie-theater

## 📚️ 개요

극장 선택을 구현한다.

## 1, 2단계

## 🛠️ 기능 요구 사항

- 영화 선택 후 극장을 선택할 수 있다.
    - 예매 완료 화면에서 극장 이름이 길 경우 말줄임표로 표시되어야 한다. (시안 참고)
- 극장별로 상영하는 영화와 상영시간은 달라질 수 있다.
- 예를 들어 시간표를 다음처럼 구성할 수 있다.

```
선릉 극장
  스타워즈(09시, 11시, 15시)
  해리포터(13시, 15시, 17시, 19시)
  
잠실 극장
  스즈메의 문단속(09시)
  해리포터(10시, 12시, 14시)
  범죄도시(11시, 13시)
```

## ✅ 구현할 기능

- [x] 극장을 선택할 수 있다.
- [x] 극장별로 상영하는 영화가 다를 수 있다.
- [x] 극장별로 상영하는 시간이 다를 수 있다.
- [x] 극장 목록을 화면 하단에서 올라오는 창으로 보여줄 수 있다.
- [x] 제목이 길어지면 말줄임표로 표시한다.
- [x] 하단 네비게이션을 통해 화면을 전환할 수 있다.

## 3, 4단계

## 🛠️ 기능 요구 사항

- 내비게이션의 예매 내역 항목에 예매한 영화 목록을 보여준다.
    - 예매 내역 : 예매한 영화 목록
    - 홈 : 영화 목록
    - 설정 : 빈 화면
- 예매 내역 상세
    - 예매 내역을 터치하면 예매 정보를 보여준다.
    - 리스트 항목을 누르는 효과를 줘야 한다. (시안 참고)
- 앱을 재실행해도 기존 예매 내역이 유지되어야 한다.
- 설정에서 알림 기능을 On/Off 할 수 있다.
    - 사용자가 앱을 재실행해도 설정 데이터가 남아있어야 한다.
- 영화 시작 시간 30분 전에 푸시 알림이 온다.
- 푸시 알림을 클릭하면 예매 정보를 보여준다.

## ✅ 구현할 기능

- [ ] 예매한 영화 목록을 볼 수 있다.
    - [ ] 앱을 재실행해도 예매 내역이 유지된다.
- [ ] 예매 내역을 터치하면 해당 예매 정보를 볼 수 있다.
    - [ ] 예매 내역을 터치하면 회색으로 터치된 항목이 표시된다.
- [ ] 설정에서 알림 기능을 on / off 할 수 있다.
    - [ ] 앱을 재실행해도 설정 데이터가 유지된다.
    - [ ] 예매한 영화 시작 시간 30분 전에 알림이 온다.
    - [ ] 알림을 누르면 해당 예매의 정보를 보여준다.
