# android-movie-theater

## 메인 화면

- [x] 영화 예매 내역, 홈, 설정 화면으로 이동(navigate)할 수 있다.
    - 예매 내역 : 예매 내역 목록
    - 홈 : 영화 목록
    - 설정 : 푸시 알림 수신 여부 설정 화면

### 예매 내역 페이지

- [x] 예매 내역 버튼을 클릭하면 예매 내역 목록이 표시된다.
- [x] 예매 내역을 터치하면 예매 정보를 보여준다.
- [x] 리스트 항목을 누르는 효과를 줘야 한다. (시안 참고)
- [x] 앱을 재실행해도 기존 예매 내역이 유지되어야 한다.

## 영화 목록 페이지

- [x] 영화를 선택하면 상영이 가능한 극장들이 표시된다.
- [x] 극장별로 상영하는 영화와 상영시간은 달라질 수 있다.
- [x] 극장을 선택하면 영화 예매 페이지로 이동한다.

## 영화 좌석 선택 페이지

- [x] 좌석 선택 완료 버튼을 누르면 영화 예매 완료 페이지로 이동한다.

## 영화 예매 완료 페이지

- [x] 예매 완료 시 극장 정보를 포함한 예매 정보가 표시된다.
    - [x] 극장 이름이 길 경우 말줄임표로 표시한다.

## 푸시 알림

- [x] 설정 뷰에 알림 푸시 알림 수신 여부를 on/off 할 수 있다.
- [ ] 앱을 재실행해도 기존 푸시 알림 수신 여부가 유지되어야 한다.
- [ ] 영화 시작 30분 전에 푸시 알림이 온다.
- [ ] 푸시 알림을 클릭하면 영화 예매 정보를 보여준다.
- [ ] Notification 아이콘은 커스텀한다.
