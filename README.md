## 기능 요구 사항

- 내비게이션의 예매 내역 항목에 예매한 영화 목록을 보여준다.
  - 예매 내역 : 예매한 영화 목록
  - 홈 : 영화 목록
  - 설정 : 알림 On/Off


- 예매 내역 상세
  - 예매 내역을 터치하면 예매 정보를 보여준다.
  - 리스트 항목을 누르는 효과를 줘야 한다. (시안 참고)
  - 앱을 재실행해도 기존 예매 내역이 유지되어야 한다.


## 프로그래밍 요구 사항
- DataBinding을 사용해야 한다.
- Room을 사용하여 데이터를 관리한다.
- 알림 권한 Dialog 및 Notification은 기본 UI를 그대로 사용한다.
  - 단, Notification의 아이콘은 커스텀해본다.

## 구현 기능 목록

- [x] 극장은 영화 번호와 상영 시간을 가진다
- [x] 극장별 특정 영화의 상영 시간표를 알 수 있다
- [x] 예매 내역을 저장한다
- [x] 예매 내역을 조회한다
- [x] 사용자가 앱을 재실행해도 설정 데이터가 남아있어야 한다.
- [x] 영화 시작 시간 30분 전에 푸시 알림이 온다.
- [x] 푸시 알림을 클릭하면 예매 정보를 보여준다.


### 영화 예매 내역 화면

- [x] 영화 예매 내역을 보여준다
- [x] 특정 예매 내역을 선택하면 상세 정보 화면으로 이동한다


### 영화 목록 화면

- [x] 영화별 예매 가능한 극장을 선택할 수 있다
- [x] 예매 가능한 극장을 선택 시 영화 예매 화면으로 이동한다


### 예매 상세 정보 화면

- [x] 예매한 티켓의 상세 정보를 보여준다


### 설정 화면
- [x] 설정에서 알림 기능을 On/Off 할 수 있다.
