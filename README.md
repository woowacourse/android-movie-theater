# 🎬 android-movie-theater

## 📚️ 개요
극장 선택을 구현한다.

## 🛠️ 기능 요구 사항
- 영화 선택 후 극장을 선택할 수 있다. 
  - 예매 완료 화면에서 극장 이름이 길 경우 말줄임표로 표시되어야 한다. (시안 참고)
- 극장별로 상영하는 영화와 상영시간은 달라질 수 있다.
- 예를 들어 시간표를 다음처럼 구성할 수 있다.

```
선릉 극장
  스타워즈(09시, 11시, 15시)
  해리포터(13시, 15시, 17시, 19시)
  
잠실 극장
  스즈메의 문단속(09시)
  해리포터(10시, 12시, 14시)
  범죄도시(11시, 13시)
```

## ✅ 구현할 기능
- [ ] 극장을 선택할 수 있다.
- [ ] 극장별로 상영하는 영화가 다를 수 있다.
- [ ] 극장별로 상영하는 시간이 다를 수 있다.
- [ ] 극장 목록을 화면 하단에서 올라오는 창으로 보여줄 수 있다.
- [ ] 제목이 길어지면 말줄임표로 표시한다.
- [ ] 하단 네비게이션을 통해 화면을 전환할 수 있다.
