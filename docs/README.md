# 🎬 영화 극장 선택

## 🛠️ 기능 요구 사항

### 🏠 홈: 영화 목록 화면
- [x] 영화의 목록이 표시된다.
- [x] 목록에는 영화 3개마다 광고 1개가 표시된다.
- [x] 목록에는 영화와 광고가 최대 10,000개까지 표시될 수 있다.
- [x] 각 영화의 제목, 포스터, 이름, 상영 기간과 러닝 타임이 표시된다.
- [x] 특정 영화의 `지금 예매` 버튼을 눌러 해당 영화를 상영하는 극장 목록을 표시할 수 있다.

### 🏠 홈: 극장 목록 화면
- [x] 선택한 영화를 상영하는 극장 목록이 표시된다.
- [x] 각 극장의 이름과 상영 시간의 개수가 표시된다.
- [x] 특정 극장을 눌러 선택한 영화와 극장에 대한 예매 화면으로 이동할 수 있다.

### 🏠 홈: 예매 화면
- [x] 선택한 영화의 제목, 포스터, 이름, 상영 기간과 러닝 타임이 표시된다.
- [x] 상영 날짜와 상영 시간의 목록을 통해 날짜 및 시간을 선택할 수 있다.
- [x] 이미 지나간 상영 날짜 또는 시간은 목록에 표시되지 않는다.
- [x] `+`/`-` 버튼을 눌러 예매 인원을 증가/감소시킬 수 있다.
- [x] 예매 인원은 1 이상, 극장의 총 좌석 개수 이하의 값으로만 선택할 수 있다.
- [x] 선택한 예매 인원이 표시된다.
- [x] 화면이 전환돼도 입력한 정보가 유지된다.
- [x] `선택 완료` 버튼을 눌러 좌석 선택 화면으로 이동할 수 있다.

### 🏠 홈: 좌석 선택 화면
- [x] 영화의 제목과 예매할 표의 총 가격이 표시된다.
- [x] 영화관의 스크린과 좌석 배치가 표시된다.
- [x] 좌석은 S급(3~4행, 15,000원), A급(5행, 12,000원)과 B등급(1~2행, 10,000원)으로 분류된다.
- [x] 좌석을 클릭하면 선택되며, 선택된 좌석을 다시 클릭하면 선택이 취소된다.
- [x] `예매 화면`에서 선택한 예매 인원수만큼 선택해야 `확인` 버튼이 활성화된다.
- [x] `확인` 버튼을 누르면 예매를 확인하는 다이얼로그가 표시된다.
- [x] 다이얼로그의 배경을 클릭해도 경고창이 닫히지 않는다.
- [x] 다이얼로그의 `확인` 버튼을 눌러 예매 완료 화면으로 이동할 수 있다.

### 🏠 홈: 예매 완료 화면
- [x] 예매한 영화의 제목, 상영 날짜 및 시간, 인원수, 좌석, 극장 이름 및 가격이 표시된다.
- [x] 극장 이름이 길어 한 줄에 전부 표시할 수 없을 경우 말줄임표로 표시된다.
- [x] 예매 완료 화면에서 뒤로 가기 버튼을 누르면 홈 화면으로 돌아간다.

### 🗒️ 예매 내역
- [x] 홈 화면에서 예매한 예매 내역이 표시된다.
- [x] 각 예매 내역의 상영 날짜 및 시간, 극장 이름과 영화 제목이 표시된다.
- [x] 특정 내역을 눌러 예매 완료 화면으로 이동할 수 있다.

### ⚙️ 설정
- [x] 스위치로 알림 기능을 On/Off 수 있다.
- [x] 앱을 재시작해도 설정 정보가 유지된다.
- [x] 알림 기능이 On일 경우 예매한 영화의 시작 시간 30분 전에 푸시 알림을 보낸다.
- [x] 푸시 알림을 눌러서 예매 완료 화면으로 이동할 수 있다.
